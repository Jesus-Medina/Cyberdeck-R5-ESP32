# Lilith — explorador pseudo-3D

Sitio interactivo estático sin dependencias de compilación. Está en español y utiliza CSS 3D, SVG y JavaScript. Las ubicaciones son conceptuales, no planos de fabricación. Los valores de voltaje/corriente son históricos, no en vivo. Los toggles SW0/SW1 son solo simulación visual.

Para publicar en GitHub Pages, elegir Settings → Pages → Build and deployment → Source: GitHub Actions. La cuenta GitHub debe admitir Pages en un repositorio privado; no cambiar la visibilidad del repo sin aprobación. El workflow despliega únicamente esta carpeta `site/`.
